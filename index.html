The tree: six areas, one engineer

Backend

  • IUDX Data Sandbox (2022 to 2025). Jupyter notebooks next to datasets. Go API with Keycloak JWT auth and build progress over Server-Sent Events. 70 of 93 backend commits.
  • Data marketplace file service (2025). TypeScript and Express, S3 and MinIO multipart uploads, presigned URLs, Keycloak and policy checks, Redis job queue. 85 of 105 commits.
  • IUDX Video Server (2021). Proxies live camera feeds from city servers behind NAT to the cloud, with load balancing and an API.
  • EpikInDiFi. Listings moved to GraphQL (32% faster), async vendor integrations over RabbitMQ and Socket.IO, MongoDB text search.

DevOps and Kubernetes

  • Hybrid storage and clusters (2023 to now). Ceph, MinIO and Kubernetes across cloud and on-prem, with GPU nodes.
  • JupyterHub and BinderHub on Kubernetes for the Data Sandbox.
  • Multi-kernel notebook images (2026). Python, R, Julia, Scala. CPU image 16.1 GB to 8.1 GB, GPU image 38.9 GB to 26.5 GB.
  • Observability. Prometheus, Grafana and Loki on Kubernetes.

Data

  • IUDX Adaptor Framework (2021 to 2023). Ingest pipeline on Apache Flink, Calcite SQL rules engine over RocksDB state, RabbitMQ and PostgreSQL sinks. Top contributor, 178 of 435 commits. Benchmarked JS engines and moved transforms from Rhino to Nashorn.
  • Analytics at volume (2023 to now). ClickHouse clusters holding billions of rows, sub-second queries, fed by Azure Functions and Event Hubs.

Frontend

  • In-browser Parquet previews via DuckDB in the marketplace file service.
  • Latitude Fintech. A Chrome extension that records clicks into guided product tours.
  • Angular, React, Next.js and ECharts.

Research

  • 4 papers on land use and land cover segmentation from satellite imagery: IEEE InGARSS 2024, two on arXiv in 2024, one on arXiv in 2025.
  • Learning What to Remember (IISc). Streaming memory for vision-language models. The learned memory did not beat the recent-frames baseline, and the report says so.
  • GPT-2 fine-tuned on Mizo (IISc). Test perplexity 680 to 22.5.
  • KYC OCR at EpikInDiFi with Tesseract and Detectron2, 96% accuracy.

Side projects private for now

  • videopipe. Videos written as code: HTML and GSAP scenes rendered in headless Chrome.
  • agent-skills. 30 skills for Claude Code and Codex.
