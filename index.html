[ 01 / 05 · Ingest ]

Many sources, one stream.

City systems speak a dozen protocols. I wrote most of the framework that pulls them in, reshapes them and streams them into the exchange.

IUDX Adaptor Framework 2021 – 2023

A configurable ingest pipeline on Apache Flink. RabbitMQ and PostgreSQL sinks, JSONPath and JavaScript transforms, checkpointing, and Prometheus, Grafana and Loki on Kubernetes. Top contributor, 178 of 435 commits.

IUDX Video Server 2021

Proxies live camera feeds from city servers behind NAT out to the cloud, with load balancing and an API on top.

[ 02 / 05 · Key by, window ]

Split by key, cut into windows.

Events fan out by key and close in event-time windows. The ones that arrive after the watermark go to a side output instead of being lost.

Streaming rules engine 2022 – 2023

Apache Calcite SQL evaluated over streams buffered in RocksDB state, with event-time timers, state expiry, and an API to add, test and delete rules while the job runs.

[ 03 / 05 · Store ]

Columns, not rows.

The stream lands in columnar storage so a question over billions of rows comes back in under a second.

Analytics at volume 2023 – now

ClickHouse clusters for high-velocity transaction data, fed in real time by Azure Functions and Event Hubs.

Hybrid storage and clusters 2023 – now

Ceph and MinIO backends and Kubernetes across cloud and on-prem, including GPU nodes for ML workloads.

[ 04 / 05 · Serve ]

Out to everyone who needs it.

Data is only useful once people can reach it. These are the platforms that hand it out.

IUDX Data Sandbox 2022 – 2025

Jupyter notebooks next to the exchange's datasets. A Go API with Keycloak auth, build progress streamed over Server-Sent Events, JupyterHub and BinderHub on Kubernetes. 70 of 93 backend commits.

Data marketplace file service 2025

S3 and MinIO multipart uploads, short-lived presigned URLs, policy checks, and in-browser Parquet previews through DuckDB.

Multi-kernel notebook images 2026

Python, R, Julia and Scala in one Jupyter image. CPU image cut from 16.1 GB to 8.1 GB, GPU image from 38.9 GB to 26.5 GB.
